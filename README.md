# 算法训练计划 · 12 周

面向面试的系统性算法训练。**170 道题,12 周走完第一轮。**

## 三条规则

1. **每天 60–90 分钟**:新题 1 道(限时 30 分钟)+ 复习旧题 1 道(15 分钟)+ 写错题本(10 分钟)
2. **每周六只复习,不碰新题** —— 用来清空积压
3. **一道题超过 25 分钟没思路 → 看题解**,但只看到「关键洞察」就停,合上自己重写一遍

## 判断「真的掌握了」

四条同时满足才算过:

- [ ] 不看任何资料,20 分钟内写出正确代码
- [ ] 能一句话说清核心思路
- [ ] 能说出时间 / 空间复杂度
- [ ] 能处理所有边界,并且知道自己容易错在哪

## 语言约定

仓库支持五种语言,但**你刷题时只用一个主语言**。

| 语言 | 目录 | 适合谁 |
|---|---|---|
| Python | `solutions/python/` | 目标不明确 / 外企 / 算法岗(默认推荐) |
| Java | `solutions/java/` | 国内大厂 Java 后端岗 |
| C++ | `solutions/cpp/` | 国内大厂 / 算法岗 / 竞赛 |
| Go | `solutions/go/` | Go 岗位(字节、B站、云原生) |
| TypeScript | `solutions/typescript/` | 前端 / Node 岗位 |

规则:

1. **主线固定一门**,刷题过程中不要换 —— 模板会打架,错题本会失效
2. 其他语言目录是给「后来用第二语言重写同一题」用的,不是每道题写五遍
3. 切换只发生在两种时机:**面试前 2 周**切到面试语言重做 20 道高频题;或**目标岗位确定后**把主线换掉,旧文件保留不删

命名规范和各语言模板见 [`solutions/README.md`](./solutions/README.md)。

## 三轮路线

| 轮次 | 时间 | 做法 |
|---|---|---|
| 第一轮 | 12 周 | 按专题铺开,允许看题解,重点建立模型 |
| 第二轮 | 4 周 | 只重做错题本里的题,不看题解 |
| 第三轮 | 2 周 | 随机抽 40 道限时 20 分钟,模拟面试 |

第一轮是否成功,只看一个指标:**能否不看资料,把双指针、二分、回溯、二叉树遍历、背包这五个模板各手写一遍。**

## 每日流程

1. 从当周 `docs/week-XX.md` 里挑一道未完成的题
2. 生成解题文件:`scripts/new.sh python 15`(自动定位周目录和权威 slug)
3. 限时 30 分钟独立完成,卡住先写下「卡在哪」
4. 完成后把周文件里的 `- [ ]` 改成 `- [x]`,GitHub 上直接点也可以
5. 做错的题复制 `templates/错题本.md` 到 `notes/`,填完「下次提醒」
6. 每周日更新 `progress.md` 一行
